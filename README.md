# 🎮 Multi-Feature Web Application (JavaScript Project)

## 🚀 Overview
This is a frontend web application built using HTML, Tailwind CSS, and JavaScript.  
It includes authentication, interactive mini-games, and a simple reward/bonus system.

The project demonstrates **frontend development, UI logic handling, and state management using browser storage**.

---

## ✨ Features

### 🔐 Authentication System
- User signup and login using LocalStorage
- Simple session handling

### 🎮 Interactive Games
- Ludo Dice Prediction Game
- Spin Wheel Game
- Card Flip Game (Red/Black prediction)

### 💰 Reward System
- Bonus points based on game outcomes
- Simple scoring mechanism

### 💳 Transaction UI (Simulation)
- Deposit interface
- Withdraw interface using bonus balance

---

## 🛠 Tech Stack
- HTML5
- Tailwind CSS
- JavaScript (Vanilla)
- LocalStorage API

---

## 🎯 Project Purpose
This project was built to practice:
- Frontend UI development
- JavaScript logic handling
- State management in browser
- Interactive user experience design

---

## 📁 How to Run
Simply open `index.html` in any modern browser.
